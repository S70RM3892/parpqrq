## 落第の理由（直す順。上ほど点が上がる）

1. **[グラフィック・楽しさ] 1人称の腕が黒い円筒。スライドに脚が無く、下を向くと脛が浮いている**
   - 証拠：`hand_swing_0.png` と `hand_zip_0.png` では、腕が模様の無い黒い円筒（先が太い）で、画面の下半分を斜めに塞いでいる。肘も装甲も無い。`hand_climb_0.png` も同じ黒い棒。`hand_slide_0.png`（SLIDE の10フレーム後）に脚が写っていない。手は指が横に6本並んで見える（(960〜1140, 950〜1080) を拡大。モデルは4本＋親指なので、親指か左右の手が重なっている）。`a4_4-4_down_0.png` では、脛が1本だけ腰なしで浮いていて、左手（黒い甲にオレンジの画面）と右手（白い骨のような指）が別物に見える。スイングとジップラインは、技の間ずっと腕が画面にある。Mirror's Edge は脚・腕・胴が画面に出て、何百もの1人称の動きを作り、それを GDC で発表している（出典）。

## 見つけた不具合
1. スイング・ジップライン・クライムの腕が、模様の無い黒い円筒（`hand_swing_0.png`、`hand_zip_0.png`、`hand_climb_0.png`）。**今回の変更（c1f959b）で入った退行。**
2. スライド中に脚が写らない。手の指が横に6本並んで見える（`hand_slide_0.png` 下中央）。
3. 下を向くと脛が1本だけ浮いている（腰が無い）。左右の手の材質が違って見える（`a4_4-4_down_0.png`）。
4. 夜の看板が真っ白に飛び、広告の絵が見えない（`a4_4-2_1.png` 左）。
5. ガラスの床に何も映らない（`a4_4-2_3.png`）。
6. Perfect だけでエースが取れるのに、「DEV and ACE need shortcuts」と書いてある（`w_results_1.png` と `ui_courses_0.png`）。
7. コースカードに「Shortcuts 4 / 3」（`ui_courses_0.png` の 2-3）。見本の記録が原因だが、`game.gd` 47行は保存された名前の数をそのまま出し、いまのコースの近道と照らし合わせていない。コースの形を変えたあと、古い記録が数を超えることがある。
8. 室外機のファンが平らな黒い楕円。側面の模様が縦の筋に伸びている（`a1_1-3_3.png` 右下）。
9. 夜・雨上がりのコースの終了時に「7 RIDs of type "Texture" were leaked」（`a4_4-2.log` ほか）。
10. 「[Physics interpolation] MultiMesh interpolation is being triggered from outside physics process」（`backdrop.gd` 372・381行。`a2_2-3.log`、`a4_4-2.log`）。動くクレーンや電車がカクつく恐れがある。
11. course_test の途中で「Jolt Physics job system exceeded the maximum number of jobs」の警告（本体の course_test の出力）。
12. 人の模型が 1-1 で4回壁に激突する（z = −76.7 / −155.3 / −166.0、空中）。最初のコースが一番激突の多いコースになっている。

## 良くなった所（証拠付きのものだけ）
- 手触りの数値に手を付けずに（sha256 一致）、見た目・バランス・音を大きく変えた。テスト3本は終了コード0。
- 材質：ルートの壁の輝度の変動係数が 0.41〜1.7% → 8.7〜13.1%。床の目地・骨材・縞鋼板・雨だれがある（`a1_1-3_0.png`、`a2_2-3_2.png`）。
- 後処理：画面下半分の白飛びが 最大43.3% → 1.8%以下（AgX）。MSAA で電線が滑らか（`a1_1-3_2.png` を拡大）。床の縞が無い。
- 夜：光源4種類、色のある光だまり3色、水たまりにネオンが映る（`a4_4-2_0.png`、`a4_4-2_3.png`、`a4_4-4_down_0.png`）。看板がルート側を向いた。
- 遠景：外壁の種類、セットバック、縦の看板、電波塔・クレーン、鳥・旗（`a2_2-3_0.png`、`a1_1-1_up_0.png`、`hand_zip_0.png`）。
- バランスの仕組み：5段のメダルを式で決め、course_test がカタログとの一致・近道の段・チェックポイント・技を教える順・床の印の位置を全部調べる。金の余裕は +4.0〜+5.1% に揃った（前回 −1.2〜+5.0%）。
- 近道：15種類。どの型も4コース以下、エリア専用の型が3つずつ（course_test の出力）。目印は銀か5回ゴールで出る。
- 繰り返す理由：開発者のゴースト（金）、記録表（エース。`w_results_1.png`）、メダルと近道の合計（`ui_title_0.png`）。
- 音：5曲・2分超・44.1 kHz ステレオ、足音32種類、エリアごとの残響（ffprobe、`default_bus_layout.tres`、`docs/AUDIO.md`）。
- UI：見出しと本文のフォント、数え上げとスタンプ（0.93 s、飛ばせる）、コースカードの絵。16:9 と 20:9 で重なり無し（`ui_*`、`w_ui_*`、`w_results_1.png`）。
- 審査の道具：`--pitch`、技の最中の手、20:9 がギャラリーに入り、確かめられる範囲が広がった。
- 描画の予算：draw calls 最大94、primitives 最大17.7万（目安の12%）。
