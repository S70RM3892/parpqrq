# 音（BGM・効果音・残響）

審査 #9「音楽と効果音が試作の水準」への答え（docs/exams/round-1.md）。素材は全部 `tools/build_audio.gd` が合成する（録音・外部素材なし）。
再生は `scripts/autoload/audio.gd`（BGM・画面の効果音・残響の切り替え）と `scripts/player/player_audio.gd`（プレイヤーの音）。

```
godot --headless --path . -s tools/build_audio.gd                       # 全部作り直す（BGM は5曲を別スレッドで。数分〜10分）
godot --headless --path . -s tools/build_audio.gd -- --only=sfx,loops   # 効果音と環境音だけ（2秒弱）
godot --headless --path . -s tools/build_audio.gd -- --only=night       # 1曲だけ（morning / noon / evening / night / menu）
godot --headless --path . --import                                      # 作ったら取り込み直す
```

オプション: `--timing`（各段階の時間）、`--wav`（ffmpeg を使わず WAV のまま書く）。乱数の種は固定なので、同じコードなら同じ音になる。

## BGM：5曲

エリアごとに1曲 + メニューの1曲。**どの曲もループするまで 2:13 以上**。
曲の最後（アウトロ）が頭（イントロ）につながるので、**ループ点は曲の頭**。頭からはみ出した残響・音のしっぽは頭へ重ねてあり、継ぎ目で音が切れない
（イントロの後ろにループ点を置くと、イントロの残響が継ぎ目に重なって段差が出る）。

### 勢い値で重ねる3層

1曲 = 3つの層（ドラム / ベース / リード）。**同じ長さの3つのファイルを `AudioStreamSynchronized` で同期して**鳴らし、層の音量だけを動かす（拍はずれない）。

| 層 | 入る勢い値 | 中身 |
| --- | --- | --- |
| drums | 常に | キック・スネア・クラップ・ハット・シェイカー・金属・タム・クラッシュ・ライザー |
| bass | 35% から | ベース（サブ・リース）+ パッド（+ 夕・メニューの曲ではエレピの和音） |
| lead | 70% から | リード・アルペジオ・和音の刻み（エレピ・スタブ） |
| （全体） | 100% | 全体を一段上げる（0.85 → 1.0） |

メニューでは3層とも鳴らす（0.8 / 0.9 / 0.9）。曲は全部 3層を足した時のピークが約 -1.5 dBFS（Ogg にすると +1 dB 前後はみ出すので余裕を取る）。再生側は Music プレイヤーを -3 dB にして、効果音の余地を残す。

### 曲を切り替える（audio.gd）

- 走行中は `PlayerAudio` がコースのエリアの時間帯（`course.area.time`）を `Audio.set_mode(RUN, area)` に渡す。タイトルは `set_mode(MENU)`（今までと同じ呼び方）
- 曲が変わる時は2組のプレイヤーで **2秒の等パワー・クロスフェード**。同じ曲なら何もしない（同じエリアの次のコースへ進んでも、リトライしても曲は頭に戻らない）
- 曲の層はその時だけ読む（5曲 15ファイルを起動時に全部読まない）。ヘッドレスでは鳴らさない・読まない（`Audio.enabled`）
- 読み込みは `.ogg`、無ければ `.wav`（ffmpeg が無い環境で `--wav` で作った曲）。Ogg のループ点は `.ogg.import` の `loop=true` / `loop_offset`（ツールが書く）。万一 `loop` が false なら読み込み時に true にする

## 合成の中身（`tools/build_audio.gd`）

**部品**（スレッドから呼ぶので全部 static、`Dsp`）

| 部品 | 作り方 |
| --- | --- |
| ノコギリ波・矩形波 | PolyBLEP の帯域制限（折り返しノイズを抑える）。全ての音程のある音がこれか正弦波・FM |
| フィルタ | 1次（足音など）、2次 RBJ、**カットオフを動かせる2次の状態変数フィルタ**（ベースの口の開閉、パッドのゆっくりした開閉） |
| 残響 | **6本のフィードバック遅延網（FDN）**。Householder の混合、各線の高域吸収（damping）、入力に全域通過2段の拡散、プリディレイ、左右は別の線から取り出して無相関に |
| ディレイ | テンポに同期した**ピンポンディレイ**（付点8分、左→右→左、反復ごとに暗くなる）。アルペジオとリードに |
| コーラス | 左右逆位相に揺らす変調遅延 |
| 幅 | 中央と両脇に分けて両脇を倍率で増減 |
| リミッタ | 3層を足した音から**共通のゲイン**を作り全層に掛ける（先読み 1 区画、戻り 80 ms）。最後に実際に鳴る組み合わせ（ドラムだけ・ドラム+ベース・全部・ベース+リード）の最大ピークを -1.5 dBFS に揃える |

**音色**

| 音 | 作り方 |
| --- | --- |
| キック | 周波数が指数で下がる正弦波（f0 → f1）+ 頭の「カツッ」（高域の雑音 + 短い 1.7 kHz）+ 軽い飽和 |
| スネア | 胴鳴り（2つの音、頭で少し高い）+ 帯域雑音。夕方の曲は**ゲートリバーブ**（長い雑音を 0.3 秒で急に切る）+ クラップを重ねる |
| クラップ | 短い雑音を 9〜11 ms ずらして3〜4回、最後だけ長く |
| ハット | 高域の雑音 + 非整数倍の正弦波6本。**強さで3種**を使い分け、さらに音量とタイミング（±1 ms）をばらつかせる |
| 金属（昼） | 調和しない比（1 : 2.76 : 5.4 : 8.9 : 13.3）の倍音が次々に消える。低・中・高の3種 |
| ベース | ノコギリ（またはパルス）を**口が頭で開いて閉じる**ローパスに通し、下に正弦波を足して歪ませる（朝・昼・夕）。夜は歪ませたサブ正弦波 + リース（少しずれた3本のノコギリ、ゆっくり揺れるローパス） |
| パッド | 少しずつ音程をずらした**ノコギリを 5〜7 本 × 構成音**重ね、左右に散らす（スーパーソー）。全体を**LFO でゆっくり開閉するローパス**に通す（区間ごとに [始め, 終わり] の口を指定して、ブレイクで閉じてビルドで開く）。声部の動きが小さくなる転回を選ぶ |
| エレピ・ベル | 2オペレータの FM（頭だけ荒く、すぐ素直になる）+ 頭の「チン」。ベルは変調の比が非整数 |
| リード | 少しずらした2本のノコギリ（左右に振る）+ 1オクターブ下のパルス、遅れてかかるビブラート、頭は少し下から入る |
| サイドチェイン | キックのたびにパッド・ベース・リードのゲインが下がって戻る（曲ごとに深さと戻りの秒数） |
| 仕上げ | 層ごとに実効値をそろえる → 軽い飽和（tanh、小さい音はそのまま）→ 幅 → 残響 → 28 Hz 以下を切る → しっぽを頭へ → 共通のリミッタ |

**書き方**: 曲は `DEFS`（ファイルの終わり）に、小節 × 16分音符で書く。ドラムは 16文字 = 1小節のパターン（`.` 休み、`1`〜`9` 強さ。複数小節ぶん書くと周期になる）、メロディとアルペジオは「コードの構成音の何番目か」で書くので、コードが変わっても和音に合う。

| 足音 | 4素材（コンクリ・金属・ガラス・砂利）× **8種** | かかとの「コツ」+ 低い「トン」+ 靴底の「ザッ」+ つま先の2発目。金属は毎回違う倍音の比、ガラスは高い鳴り、砂利は粒の数と散らばりを毎回変える。再生は `AudioStreamRandomizer`（同じ音が続けて鳴らない、ピッチ **±4%**、音量 ±1.5 dB）|
| 着地 | 軽・中・重 × **3種** | 重いほど低音が長く、中以上は擦れ、重は低いドンと砂利の跳ね |

| 風・息・スライド | ループ | 44.1 kHz（風はステレオで左右別のノイズ）。残響は通さない |
| その他 | | ジャンプ・ローリング・墜落・Perfect・復帰・チェックポイント・区間・ゴール・メニュー（今までと同じ。44.1 kHz） |

### エリアごとの残響（SFXRoom バス）

足音・着地・掴み・ジャンプなどプレイヤーの音は **SFXRoom バス**（Delay → Reverb）を通って SFX に流れる。風・息・スライドの擦れと画面の音は通さない。`Audio.set_room(area)` が曲と同時に切り替える。

| エリア | 想定 | Reverb（room / damping / wet / プリディレイ） | Delay |
| --- | --- | --- | --- |
| 朝（屋上） | 開けている：短く、まばら | 0.14 / 0.6 / 0.05 / 6 ms | なし |
| 昼（工事中の高層） | 鉄骨とコンクリート：金属の小さな反射 | 0.30 / 0.3（明るい）/ 0.09 / 12 ms | 38 ms・-17 dB |
| 夕方（繁華街の路地） | 壁に当たって返る：**スラップバック** | 0.24 / 0.5 / 0.08 / 10 ms | 110 ms・-9 dB（左）と 190 ms・-17 dB（右） |
| 夜（駅） | **長く暗い** | 0.85 / 0.78（暗い）/ 0.22 / 28 ms | なし |
| メニュー | ほぼ乾いている | 0.20 / 0.55 / 0.04 / 8 ms | なし |

Master バスにはリミッタ（天井 -1 dB）を入れてある（曲と効果音が重なって 0 dBFS を超えないように）。

## 測定

耳では確かめられないので、数字で確かめる。`tools/build_audio.gd` が曲ごとに出力する（`PEAK_DB` = -1.5）。全部 44.1 kHz ステレオ。
ピークと RMS は 0 dBFS = 1.0、「全部」= 3層を全部重ねた音。層ごとの RMS は音のある所だけの値。重心 = スペクトル重心（Hz、曲の 24 か所の平均）。

- 左右の相関は全曲 0.95 未満（0.67〜0.85）。ドラムの層だけは中央のキックが主なので 0.97〜0.99（ベースとリードを足すと下がる）
- リミッタが削った量は最大 1.7〜2.2 dB
- Ogg にエンコードして戻すとピークが +0.5〜1.1 dB はみ出す（ffmpeg で戻して測ると -0.40〜-0.95 dBFS）。0 dBFS を超えるものは無い

### 容量

| | 容量 |
| --- | --- |
| `assets/audio/` 全体（git に入る） | 31 MB |
| BGM 15 ファイル（Ogg Vorbis、層ごとの品質 4 / 3 / 3.5） | 27.2 MB（1曲 5.0〜5.9 MB） |
| 効果音と環境音 65 ファイル（WAV） | 3.4 MB（QOA で取り込むと 1.3 MB） |
| 書き出し（pck）に入る分 | 約 30 MB（BGM 29 MB + 効果音 1.3 MB） |

BGM を WAV（16bit・44.1 kHz・ステレオ）のまま置くと 1 層 24 MB、全部で 350 MB を超え、git にも書き出しにも重すぎる。そのため BGM は Ogg Vorbis にした
（ffmpeg の libvorbis。ツールが `.ogg.import` にループ点を書く）。ffmpeg が無い環境では WAV のまま書き出し（`audio.gd` が `.wav` も読む）、取り込みの QOA 圧縮で書き出しは 75 MB 前後になる。
