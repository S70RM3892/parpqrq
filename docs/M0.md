## 手順

1. **Godot 4.7.x を入れる。** [ダウンロード](https://godotengine.org/download/)。
2. **プロジェクトを開いてPCで走る。** F5で起動し、テストコースを走れることを確認。
3. **Godot MCP をつなぐ。** Node.js を入れ、このフォルダで Claude Code を起動すると `.mcp.json` の `godot` サーバーが読まれる。Godotを自動検出できない時は `GODOT_PATH` を設定する（[godot-mcp](https://github.com/Coding-Solo/godot-mcp)）。
4. **Androidビルドの準備。** [公式手順（4.7）](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_android.html)どおりに:
   - OpenJDK 17 と Android SDK を入れ、エディタ設定の `Java SDK Path` と `Android SDK Path` を指定
   - エディタの「プロジェクト → エクスポートテンプレートの管理」でテンプレートを入れる
5. **実機で計測。** 端末を開発者モード＋USBデバッグにしてつなぎ、エディタ右上のAndroidボタン（ワンクリックデプロイ）で起動。
   - コントローラーをBluetoothでつなぐ
   - テストコースを1分走り回り、デバッグ表示を見る
   - `GATE 60fps: PASS` が続けば合格。`frames over 17.7 ms` が増えるなら、何をした時に増えたかを記録する

## 合格しなかった時に見る所

- `draw calls` が多い → 箱の数を減らす（M1で MultiMesh / 結合を検討）
- `cpu process` が10msを超える → スクリプトの重い処理
- どちらも低いのに落ちる → GPU。`Settings.render_scale` を 0.85 → 0.7 に下げて差を見る、影の距離 `directional_shadow_max_distance` を縮める
