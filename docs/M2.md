# M2 技の完成

**ゲート：全技が速度を落とさずにつながる。** スモークテストが自動でコースを走って確かめる（下の表）。最終判断は持ち主が走って決める。

技・勢い値・Perfect は M1 で前倒しして入れてある（docs/M1.md）。M2 で足したのは「即リトライ」の残りと、つながりの確認。

## 即リトライ（仕様書 5章）

| 操作 | 結果 |
| --- | --- |
| リトライ（Y / △ / R）を押して離す | 離した瞬間にスタートへ。計測もやり直し（押してから0.5秒以内が必達。テストでは0.12秒） |
| リトライを0.3秒押し続ける | チェックポイントへ。**計測は止めない**（戻った分だけタイムが遅れる） |
| 道より下に落ちる | すぐチェックポイントへ（コースごとの高さ `kill_y` で判定。白箱コースは -30 m） |

- 押した瞬間ではなく離した瞬間に戻すのは、長押しでチェックポイントを選んだ時に計測を消さないため
- 長押しの間は画面がうっすら白くなっていき、戻った瞬間は白から0.15秒で戻る（瞬間移動を目立たせない。読み込み画面は出さない）
- 戻ったことは `Player.respawned(to_start)` で知らせる。計測（`course_timer.gd`）は入力を直接読まずにこれを聞く

## つながりの修正

- **縦ウォールラン → 縁を登る** の後、ほぼ止まっていた（2.0 m/s）。登る速さを「壁に押し付けている速さ（約1 m/s）」で測っていたため。
  駆け込んだ速さで測るようにして、普通のクライムと同じ6 m/s で登りきるようにした（数値は変えていない）

## ゲートの自動確認（スモークテスト）

| 確認 | 合格の条件 | 現在 |
| --- | --- | --- |
| 地上で走り速度の90%を下回っていた時間（走り出してからゴールまで） | 0.3秒以下 | 0.25秒（クライム2回の登りきり直後だけ） |
| ヴォルトの速度 | 95%以上 | 103%（Perfect） |
| ウォールランの速度 | 入った速さの95%以上 | 100% |
| ローリング | +10%以上 | +13% |
| ハードランディング後 | 減速しない | 10.3 m/s |
| 壁への激突 | きれいなラインで0回 | 0回 |
| リトライ / 長押し / 落下 | 0.5秒以内にスタート / 0.3秒でチェックポイント / チェックポイント | 合格 |

## 入力の扱い

`player.gd` の入力は `_just()` / `_held()` / `_move_input()` を通して読む。`input_enabled = false` にすると何も押していない扱いになる（ゴール後・リプレイ中に使う）。
床の素材（`floor_surface`）はコライダーのメタデータ `surface` から読む（M3の足音が使う）。
