# M6 AAA化（1）：見た目の土台・メダルの付け直し・開発者のゴースト

持ち主の要望（2026-10-04）：**AAA級になるまで改善をやめない。** AAA の基準は

1. グラフィックが他のタイトルと比べて遜色ないこと
2. ゲームバランスがとても洗練されていること
3. 遊びたくなる楽しみを見つけられること

厳しい試験官（`.claude/agents/aaa-examiner.md`）を置き、各ラウンドの最初と最後に採点させる。3つとも 9.0 以上で合格。
報告は `docs/exams/round-<N>.md`。第1回は **グラフィック 3.5 / バランス 4.5 / 楽しさ 4.5（落第）**。

判断の順は仕様書のまま（手触り > 爽快さ > グラフィック、60fps を割らない）。**手触りの数値（MovementParams・カメラ演出）は変えていない。**

## 試験の道具

| 道具 | 中身 |
| --- | --- |
| `tools/gallery.sh [出力先]` | 4エリアを自動走行で走りながら撮る画面一式＋タイトルの各画面。描画の統計（draw calls・primitives）も出す。撮らない間は描画を止めるので数分で終わる |
| `tools/gallery.tscn` | 1コースを撮る（`--course=3-2 --at=5,14 --results --pitch=-40 --shortcuts`） |
| `tools/clip_metric.py` | 白飛び（画面下半分で RGB とも250以上の割合）と平均の明るさ |
| `tools/setup_cloud.sh` | クラウドのセッションで Godot 4.7.2・lavapipe（ソフトウェアの Vulkan）・xvfb を入れる（SessionStart フック） |

画面は本番と同じ Mobile レンダラー（Vulkan）で撮る。ディスプレイの無い環境では lavapipe と xvfb を使う。

## グラフィック

### 焼いた光（Mirror's Edge の見た目の核）

Mirror's Edge の白い街は Beast（Illuminate Labs）で焼いた間接光と色の滲みで作られている（[GDC 2009 "The Unique Lighting of Mirror's Edge"](https://www.slideshare.net/slideshow/henrikgdc09-compat/3128065)）。
Godot の LightmapGI はスクリプトから焼けず（[Godot Forum](https://forum.godotengine.org/t/is-it-possible-to-bake-lightmapgi-node-using-headless-godot-editor/129607)）、実行時に組むコースには使えないので、**自前で焼く**。

| 部品 | 中身 |
| --- | --- |
| `tools/lightbaker/lightbaker.cpp` | C++ の経路追跡（BVH、余弦で重みを付けた半球のサンプリング、空の見え方＋2回の照り返し、箱に埋まった画素の穴埋め、面ごとのノイズ取り）。OpenMP で全コア |
| `LevelGeometry` | 面ごとにライトマップのアトラスの場所を決めて頂点（CUSTOM1）に書く。高いビルの壁は屋上から 9 m だけ細かく焼く。面の並びの指紋（`lightmap_hash`） |
| `tools/bake_lighting.tscn` | 全16コース＋フリーラン＋タイトルの背景を焼く（約5分）。`-- --only=1-1,2-3` |
| `LevelLighting` | 形が焼いた時と同じなら材質に渡す。違えば焼く前の見た目に戻る（コーステストが「lightmap stale」で落ちる） |
| `level.gdshader` | A = 空の見え方（環境光と映り込みに AO）、RGB = 照り返し（白い壁に日向の床やオレンジの壁の色が滲む） |

**コースの形を変えたら** `godot --headless --path . res://tools/bake_lighting.tscn` で焼き直す。g++ が要る（無ければ道具が作る）。

### 材質

- 写真のテクスチャ（[Poly Haven](https://polyhaven.com)、CC0）を `python3 tools/fetch_textures.py` で落として「明るさのムラ・粗さ・凹み」と法線に詰め直す（`assets/textures/`、出典は `CREDITS.md`）。**色は材質の白のまま**で、写真は細部だけを足す
- 箱の角は法線を曲げて丸く見せる（光が角に乗る。頂点は増やさない）
- ビルの窓は奥に部屋が見える（interior mapping）。ブラインド、夜は所々灯る（`shaders/city.gdshaderinc`）
- 白い壁に雨だれ、足元のはね。ルートの面は塗装した鋼板のパネルで、角が擦れて下地が出る
- 看板に広告の絵（グラデーション・丸い印・文字の帯）
- 箱が重なった所で面がちらつかない（Zファイティング）ように、見た目だけ数mmずらす

### 光と後処理

- トーンマップを **AgX**（白 10、コントラスト 1.35）に。白い街の日向が真っ白に潰れない（白飛び 0〜2%、前は最大43%）
- **MSAA 4x**（画質「高」）
- 夕方・夜：街灯・ネオン・看板が周りを照らす（Mobile は1メッシュに灯り8つまでなので、40 m の区画ごとに5つまで）。看板は走ってくる人の方を向く
- ガラスの床・天窓の上に反射プローブ（一度だけ撮る）
- 光るもの（太陽・看板・窓）だけが滲むグロー
- 雲は太陽の側が明るく底が陰り、太陽の近くで縁が光る。上空に巻雲。星は丸い点

### 遠景の街

6種類の外壁（板状・ガラスのカーテンウォール・ベランダの集合住宅・縦の看板のある雑居ビル・古いビル・黒いガラスの塔）、セットバック、屋上の塔屋・水槽・室外機・アンテナ、航空障害灯。
エリアの目印：朝 = 電波塔、工事 = 旋回するタワークレーン3基、夕方 = 大きな画面のビル、夜 = 高架を走る電車。谷底の道に車のライトが流れ、朝は鳥の群れが回る。全部 MultiMesh 1つ。

### 1人称の体

- 手を作り直した（`FirstPersonHand`）：白い装甲・黒い関節・オレンジの光の機械の手。指が3節ずつ曲がり、袖が腕を覆う（断面が見えない）
- 状態ごとの指の形：走る = 軽く握る、空中 = 開く、ヴォルト・クライム・スライド・ハードランディング = 手のひらを着く、縁 = 引っ掛ける、バー・ジップライン = 握る。横ウォールランでは壁側の手のひらを壁に添える
- 脚も同じ白い装甲と黒い関節に塗り直した
- 足元の粒：着地・ローリングの土煙、スライドの擦れ（金属は火花）、ウォールランの擦れ。床の素材で色が変わる

## ゲームバランス（docs/BALANCE.md）

- 自動走行に「人の模型」（入力のタイミングだけを人らしくずらす。数値は変えない）を足し、メダルを付け直した
- メダルを5段に：**開発者 / エース / ゴールド / シルバー / ブロンズ**（Neon White のエースにならう）
- 近道の目印はシルバー以内、または5回ゴールしたら出る
- チェックポイントは150 mごと（シルバーのペースで20秒以下）

## 楽しさ

- **開発者のゴースト**：ゴールドを取ると、近道を全部通る自動走行の走りが薄い水色のゴーストで一緒に走る（どこが近道かが見える）。
  `godot --headless --path . --fixed-fps 60 res://tools/record_dev_ghosts.tscn` で記録し直す（コースの形を変えたら必要。古いとコーステストが落ちる）

## コースを変えた時の手順（まとめ）

1. `godot --headless --path . res://tools/bake_lighting.tscn`（光を焼く）
2. `godot --headless --path . --fixed-fps 60 res://tools/record_dev_ghosts.tscn`（開発者のゴースト）
3. コーステストを回し、出てきた5つのメダルを `course_catalog.gd` に写す
4. テスト3本が通ることを確かめる

## 残っていること（持ち主がやる）

- 実機（Android フラッグシップ機）での60fps確認。描画は撮った画面で draw calls 20〜120、primitives 2〜13万（目安の 15% 以下）
- 手の見た目の好み（形・色）、腕の振れ幅（演出の値なので持ち主が決める）
