### コースの作り（仕様書 7章の原則）

コースは「型（モチーフ）」の並びで `scripts/levels/course_catalog.gd` に書き、決まった乱数で数値を振ってレシピに展開し、
`scripts/levels/course_builder.gd` がレシピから屋上を組み立てる（ビルの屋上、谷底の通りは45 m下）。

| 原則 | 作り |
| --- | --- |
| 次の行き先が見える | 曲がり角は左右交互（ジグザグに進む）。遠景は屋上より低く、ゴールには光の柱 |
| 主ルート＋近道 | `detour`：真ん中に中庭の穴。主ルートは片側の通路を回り、真っすぐ跳ぶ／壁を走れば近道（色なし） |
| 技は1つずつ | 各エリアの1本目は新しい技を単独で出す型（intro_*）から始める |
| リズム | 同じ間隔で同じ技を並べる型（vault_rhythm・gap_rhythm・wallrun_rhythm…） |
| 高さで緊張と解放 | 細い屋上・梁を渡って、広い屋上へ大きく跳び降りる型（tension・tower・release） |
| 見えない壁を作らない | 屋上の縁は低い手すり壁か落下。走る道の外に小物 |
| 足音で素材が分かる | 屋上の床はエリアごとにコンクリ・砂利・鉄板・ガラス（駅）を混ぜる。床の乱数はコースの形と別なので、変えてもメダルは変わらない |

レシピの書き方は `course_builder.gd` の先頭。1コースの中身は `godot --headless --path . -s tools/print_course.gd -- 2-3` で見られる。
**コースを変えたら** `tests/course_test.tscn` を回し、出てきたメダルの目安を `course_catalog.gd` に書き写す（自動走行のタイムが開発者と金の間に無いとテストが落ちる）。

## 自動走行テスト（全コース）

```sh
godot --headless --path . --fixed-fps 60 res://tests/course_test.tscn           # 16コースで約45秒
godot --headless --path . --fixed-fps 60 res://tests/course_test.tscn -- --only=3-2
```

確かめること：ゴールまで落ちない・止まらない、壁への激突0回、メダルが自動走行のタイムに合っている。
自動走行（`tests/autopilot.gd`）は InputMap のアクションを押すだけで、人と同じ経路で動く。

画面の流れは `tests/flow_test.tscn`（本物の入力イベントで、初回の選択 → Play → ゴール → リプレイ → リトライ → 一時停止 → コース選択 → フリーラン）。

## 作りながら直した手触り

- **ローリング → スライド**：転がりの後半にしゃがみを押せば、そのままスライドに入る（ジャンプはもともと後半から受け付けていた）。速い着地で転がった先にバーがあると止まっていた
- 縦ウォールランから縁を登った後に止まっていたのを修正（M2）

## ゴーストとリプレイ

- 走りは物理フレームごとに全部記録する（足元・向き・カメラの位置と向き・FOV・状態・速さ）。自己ベストは `user://ghost_<id>.dat`
- ゴーストは半透明の人形で、記録の状態（走り・空中・スライド・ローリング・ぶら下がり）から手足を動かす。**22 mより離れると頭上の矢印だけ**（壁越しにも見える）
- リプレイの1人称は記録したカメラをそのまま再生する（揺れ・傾きも含めて自分が見た通り）

## フリーラン

7×7のビルを路地（3〜5 m）で区切った区画。高さはなめらかに変わり、隣との段差に応じて
木箱（ヴォルトで乗ってからクライム）・下り坂・路地をまたぐ壁（ウォールラン）・梁を置く。落ちると最後に立っていた屋上へ戻る。
