# M3 見た目と音

**ゲート：本番の見た目で実機60fpsを維持する。** 中価格帯のAndroid実機で、どのエリアのコースを走ってもデバッグ表示（F3 / Back）が `GATE 60fps: PASS` のまま。
判定は持ち主が実機で行う（エディタやPCの数字は実機の性能を映さない）。手順は下の「実機での確認」。

## 見た目（仕様書 6章）

白い街に1色（ルートカラー #FF6A1A）だけを差す。絵の美しさはポリゴン数ではなく「色・光・空気感」で作る。

| 要素 | 中身 | 場所 |
| --- | --- | --- |
| 材質 | 白い街の材質を1つのシェーダーで：屋上の1.5 m目地（走ると床が流れて速さが分かる）、ビルの窓（夜は所々灯る）、ガラス、金属、砂利、工事の縞 | `shaders/level.gdshader` / `scripts/levels/level_style.gd` |
| ルートカラー | 使える足場・縁・壁・バーだけオレンジ。**遠くは強く光り、近づくと淡くなる**。設定でOFFにでき、OFFでクリアするとメダルに印 | 同上（グローバル変数 `route_strength`） |
| 時間帯 | コースごとに固定：朝（エリア1）・昼（2）・夕方（3）・夜（4）。空・太陽・霧・トーンを一式で切り替える | `scripts/levels/atmosphere.gd` |
| 空 | グラデーション空＋太陽＋夜は星。雲は別の半球で流す | `shaders/sky.gdshader` / `shaders/clouds.gdshader` |
| 霧 | 距離の霧で遠景を白く飛ばし、**高さの霧で谷底の通りを白く消す**（高所の怖さ） | `atmosphere.gd` |
| 影 | 太陽1灯。リアルタイムの影は近距離だけ、カスケード2段（高 60 m / 低 32 m） | `atmosphere.gd` |
| 遠景 | コースの外にビルを並べる。近くは屋上より低く（下に街が広がる）、遠くに高層 | `scripts/levels/backdrop.gd` |
| 小物 | 室外機・受水槽・高架水槽・アンテナ・塔屋・手すり・看板・ネオン・照明・足場・クレーン・配管・天窓・電線 | `scripts/levels/course_props.gd` |

### スピード表現（モーションブラーの代わり、4つで「速い」を伝える）

| 表現 | 出方 |
| --- | --- |
| 速度FOV | 走り速度を超えた分に比例して最大+12°（M1から） |
| スピードライン | 画面の端だけに放射状の線。走り速度の1.07倍（仕様書の8 m/s相当）から出て、技の上限（15 m/s）で最大 |
| 速度ビネット | 同じ範囲で周辺を暗くし、視線を中央に集める |
| 風に舞う塵 | 空中の塵が後ろへ流れる。速いほど長い線 |

スピードライン・ビネット・勢い値の縁の光は **1枚のシェーダー** にまとめた（`shaders/screen_fx.gdshader`）。何も出していない時は描かない。
強さは設定の「Speed lines & vignette」（0〜100%）。

### 照準点（仕様書 8章）

小さな点1つ。**技が使える時だけ少し広がる**（ヴォルト・クライム・縦ウォールランが出せる距離、空中で横に壁がある時）。
設定「Fixed center dot」がONなら常に出す（酔い対策）。OFFなら技が使える時だけ浮かび上がる。

## 音（仕様書 5章「サウンド」）

音の素材が無いので **全部手続き的に合成** して `assets/audio/*.wav` に書き出した（`godot --headless --path . -s tools/build_audio.gd`、2秒弱）。
数値を変えて作り直せる。ループする音はWAVにループ点を書いてあり、Godotの取り込みが自動で読む（QOA圧縮、合計3 MB）。

| 音 | 仕様書 | 実装 |
| --- | --- | --- |
| 風切り音 | 速度の2乗で大きく、高音を足す。12 m/sで最大 | 低い風と高い風の2本。速度²で音量、技の上限（15 m/s、+33%後の12 m/s）で最大 |
| 足音 | 素材別（コンクリ／金属／ガラス／砂利）。速いほど間隔が詰まる | 4素材×3種。床のコライダーのメタデータ `surface` で選ぶ。足取りに同期 |
| 息づかい | 勢い値に連動。高いほど荒く速く | 勢い値で音量と再生速度（0.9→1.45倍） |
| 手が触れる音 | ヴォルト・クライム・縁掴みに「パシッ」 | 2種。壁に張り付く時も小さく |
| BGM | 勢い値で3段階（ドラム→ベース→リード） | 140 BPM・8小節の3層を同期再生。ドラムは常に、勢い35%でベース、70%でリード、100%で全体を一段上げる |
| 着地 | 落下速度で3段階。ハードランディングは低音 | 軽（普通のジャンプ）・中・重（低いドンを足す） |
| Perfect | 高い効果音 | 鐘の音 |

効果音は **Player のシグナルを受けたその物理フレーム** で鳴らす（画面の動きとずらさない）。
バスは Master / Music / SFX（`default_bus_layout.tres`）。音量は設定から。

## 仕様書から変えた点

- **LightmapGI を使わない**。コースは実行時にレシピから組み立てる（`course_builder.gd`）ので、エディタで光を焼けない。
  代わりに、床に接する所の陰と面の境目の線をシェーダーで描く（描画の追加コストなし）。空からの環境光は空のシェーダーから一度だけ作る。
- **雲は空のシェーダーではなく別の半球で流す**。空のシェーダーで `TIME` を使うと、Godot は空の放射輝度マップを毎フレーム作り直す（4.7.2 の `servers/rendering/renderer_rd/environment/sky.cpp` で確認）。モバイルでは重い。
- **反射プローブは置かない**。ガラスの映り込みは空の放射輝度マップで足りる。必要なら駅のガラス屋根に1つずつ足せる。
- **スピードラインの色は白ではなく青みのある灰色**（夜は明るく）。白い街の上では白い線が見えなかった。
- **4エリアの時間帯に「昼」を足した**（工事中の高層）。仕様書は朝・夕・夜。工事現場の黄色と鉄骨が一番読める光にした。

## 性能のための作り

| 工夫 | 効果 |
| --- | --- |
| 箱・円柱を材質ごとに1つのメッシュへまとめる（40 m四方の区画ごと） | 1コースの描画呼び出しが数十〜百程度（PCのソフトウェア描画で計測：走行中 40〜130） |
| 当たり判定は区画×素材ごとに1つの StaticBody3D | ノード数を抑える |
| 遠景のビルは MultiMesh 1つ | 300〜400棟で描画1回 |
| 画面に重ねる演出は1枚 | 全画面の読み書きを1回に |
| 空の放射輝度マップは一度だけ | 毎フレームの空の処理なし |
| 画質「低」 | 影 32 m、グローなし、塵 24本（高：60 m、グロー、56本） |
| コースの組み立て | 30〜120 ms（PC）。読み込み画面なし |

## 実機での確認（ゲート）

1. docs/M0.md の手順でAndroid実機にデプロイする（設定の「Graphics」は High のまま）。
2. 4つのエリアのコースを1本ずつ、最後まで走る（1-4・2-4・3-4・4-4 が一番長く物が多い）。F3 / Back でデバッグ表示を出しておく。
3. `GATE 60fps: PASS` が続けば合格。`FAIL` になったら、どのコースのどこで落ちたかと `draw calls`・`cpu process` をメモする。
4. 落ちる時に試すこと：設定の Graphics を Low、Render scale を 0.85 → 0.7。それで直るならGPU、直らないならスクリプト（`cpu process`）。
