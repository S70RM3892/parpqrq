# M1 手触り検証

**ゲート：同じ白箱コースを10回走っても気持ちいい。** 越えるまでM2（ウォールラン・クライム・スライド・勢い値）に進まない。
この判定は持ち主が自分の手で走って決める。数値はClaudeに任せない（CLAUDE.md）。

## コース（スタート → ゴール）

ヴォルト 1.0 m → ヴォルト 0.8 m（8 m間隔のリズム）→ 段差 0.45 m → 階段で 2.4 m の台 → 飛び降りてローリング →
深い箱に上に乗るヴォルト → ヴォルト 1.2 m → 階段で 4.8 m の塔 → 飛び降り（ローリングしないとハードランディング）→ ゴール。
自動走行のタイムは約11.5秒。主ルートの右側に、ヴォルトの上限・下限と斜めの壁（20°と30°）を試す箱がある。

## 10回走る時に見ること

1. 1〜3回目：4層を全部ONで走る。気持ちよくない所をメモする（どの技の、どの瞬間か）。
2. 調整パネルで層を1つずつOFFにして走る。何が効いていて、何が酔いの原因かを切り分ける。
3. 数値をいじる。エディタから実行していれば、Saveで `resources/movement_default.tres` に書かれ、そのままコミットできる。
4. 10回目でまだ気持ちいいか。飽きたなら、その理由が次の調整点。

## 体のモデルについて（制約）

- 元モデル（`assets/source/`、Meshy製）は**骨格なしの静的メッシュ**。指は開いたまま曲がらない。脚は膝・足首で3つに切った剛体パーツを回している。
- 胴体は無い。真下を見ると腰の付け根が見える。
- 手はカメラに付けている（ビューモデル方式）。下を見ても手は画面の下端に留まる。
- 本格的にやるなら、Blender等で骨格を入れたフルボディモデルに差し替える。差し替えても `arms.gd` / `legs.gd` の姿勢計算（角度の決め方）は使い回せる。
- モデルを差し替えたら `tools/build_body.gd` の関節位置（`LEG_HIP` など）を合わせて再実行する。

## M1に入れていないもの

- Perfect判定・ヒットストップ・勢い値（M2）、音（M3）
- ローリングのカメラは前に30°傾けるだけで、1回転はさせていない（酔い対策を優先）
- Androidでコントローラー振動が効くかは実機で確認すること
