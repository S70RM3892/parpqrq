# M1 手触り検証（M2の技を前倒しで統合）

**ゲート：同じ白箱コースを10回走っても気持ちいい。** 判定は持ち主が自分の手で走って決める。

0.1.0-beta を触った結果「技が足りないと気持ちいいかの判断もできない」となり、仕様書でM2にあった技を前倒しで入れた。
M2に残っているのは「勢い値（モメンタム）」「Perfect判定とヒットストップ」の2つ。

## 速度（0.3.0-beta で変更）

0.2.0-beta の試走で「全体的に遅い」となり、仕様書の値から+33%にした。技が出る速度の条件も同じ比率で上げ、コースの障害物の間隔も1.33倍に広げて時間間隔を保っている。

| 項目 | 仕様書 | 現在 |
| --- | --- | --- |
| 走り（通常最高） | 7.5 m/s | 10.0 m/s |
| 歩き | 2.5 m/s | 3.3 m/s |
| 技でつないだ時の上限 | 12 m/s | 15 m/s |
| ヴォルトの最低速度 | — | 5.3 m/s |
| 横ウォールラン・スライドの最低速度 | 5 m/s | 6.7 m/s |
| 縦ウォールランの最低速度 | 4 m/s | 5.3 m/s |

## 技（すべてスモークテストで自動確認）

| 技 | 入力 | 条件 | 結果 |
| --- | --- | --- | --- |
| ヴォルト | 走りながらジャンプ | 0.6〜1.3 m、奥行き1.2 m以下 | 速度95%で越える。深ければ上に乗る |
| クライム | 壁に向かってジャンプ | 縁が〜2.4 m（歩きでも可） | 0.5 sで登る。走って来ると0.375 s |
| レッジグラブ | 空中で縁に手が届く | 自動 | 前を押していれば登る、離していればぶら下がる |
| ぶら下がり中 | 左右 / ジャンプか前 / しゃがみか後ろ | — | 横移動 1.2 m/s / 登る / 手を離す |
| ウォールラン（横） | 壁沿いにジャンプ | 速度6.7 m/s以上、進入角0〜60° | 最大1.6 s、重力30%。跳んだ勢いは上向き5 m/sまで残す |
| 壁ジャンプ | ウォールラン中にジャンプ | — | 壁から離れる向きに跳ぶ。速度+10%。反対の壁にも張り付ける |
| ウォールラン（縦） | 壁に正対してジャンプ（跳んで0.5 s以内に壁に着いても可） | 速度5.3 m/s以上、縁が2.4 mより高い | +2.0 m駆け上がり、手が届けば縁を掴む。ジャンプで後ろへ蹴る |
| スライド | 走行中にしゃがみ | 速度6.7 m/s以上 | 0.8 s。下り坂では加速し続ける。当たり判定1.0 mで低い隙間をくぐれる |
| スライドジャンプ | スライド中にジャンプ | — | 速度+8% |
| ローリング | 着地の0.2 s前〜0.08 s後にしゃがみ | 2 m超の落下 | 速度+10%（Perfectならさらに+3%） |
| ハードランディング | ローリング失敗 | 4 m超の落下 | 揺れと振動だけ。止まらない（0.4.0-beta で硬直と減速を廃止） |

地上でジャンプを押した時の優先順は ヴォルト → クライム → 縦ウォールラン → 普通のジャンプ。
技の最中に押したジャンプは0.15 s前まで受け付ける（ヴォルト→ジャンプ、ローリング→クライム など）。
着地にしゃがみを合わせると、そのままスライドに入る。

仕様書から変えた点：
- ウォールランの進入角の下限を15°→0°にした（壁と平行に近く跳んだ時も張り付くように）。調整パネルの `wallrun_min_angle` で戻せる。
- ハードランディングの硬直（0.6 s）と速度70%減を廃止した（止まるのが不快）。揺れ・振動・着地の沈み込みは残す。`hard_land_stun` / `hard_land_speed_loss` で戻せる。
  代わりにローリング成功で速度+10%の上乗せを付けた（0.5.0-beta）。

## 上手いほど速くなる（仕様書 5章：勢い値とPerfect）

**Perfect判定**（理想タイミング±50 ms）：速度+3%、勢い値+10%、画面の縁が光って「PERFECT」、0.04 sだけ0.2倍速。

| Perfect | 理想タイミング |
| --- | --- |
| 着地ジャンプ | 着地の瞬間にジャンプ（続ければ跳ぶたびに+3%） |
| ローリング | 着地の瞬間にしゃがみ |
| ヴォルト | 体が障害物に着く0.15 s前にジャンプ（10 m/sなら1.5 m手前） |
| 壁ジャンプ | 張り付いて0.15 s以内に蹴る |
| スライドジャンプ | 滑り出して0.15 s以内に跳ぶ |

**勢い値**（0〜100%）：ヴォルト・ウォールラン・壁ジャンプ・ローリングで+10%、クライム・スライドで+5%、Perfectで+10%。
- 溜まるほど速度の上限が上がる（勢い0で11.5 m/s → 100%で15 m/s）。通常最高を超えた分が戻る速さも、勢いが高いほど遅い
- 減るのは、歩き速度より遅い間（毎秒50%）、壁に激突（60%失う）、ハードランディング（25%失う）。普通に走っている間は減らない
- 画面の縁がうっすらオレンジに光る強さで見える（数字は出さない）

**上達が見えるもの**
- ゴールで：タイム、自己ベストとの差、メダル、次のメダルまであと何秒、最高速度、Perfect数
- 区間（4か所）を通るたびに、自己ベストの区間タイムとの差を1.5 s（緑＝速い、赤＝遅い）
- 自己ベストの走りが半透明のゴーストとして一緒に走る
- メダル：開発者 15.5 s / ゴールド 17.0 s / シルバー 20.0 s / ブロンズ 25.0 s（自動走行はPerfect 8回で16.2 s）

## コース（スタート → ゴール、自動走行で約16.2秒）

ヴォルト 1.0 m → ヴォルト 0.8 m（約1秒間隔）→ 段差 0.45 m → 階段で 2.4 m → 飛び降りてローリング → 深い箱に乗る → ヴォルト 1.2 m →
階段で 4.8 m の塔 → 飛び降り → **スライドでバーをくぐる** → チェックポイント → **ウォールランで9 mの穴を越える** →
**2.4 mの壁をクライム** → 飛び降り → **4 mの壁を縦ウォールラン→縁を掴んで登る** → ゴール。
穴（12 m）に落ちるとチェックポイントへ戻る。
階段には段の角を結ぶ見えない坂が重ねてあり、走ると坂に乗って滑らかに上がる（段だけだと1段ごとに体が跳ねて詰まる）。リトライ（Y / R）はスタートへ戻る。

コース外の試し場：壁ジャンプ回廊（x=14〜18、左右交互）、下り坂（スライド加速）、2.0 mの箱（歩いてクライム・ぶら下がり）、
6 mの壁（縦ウォールランでも届かない）、ヴォルトの上限・下限、斜め20°/30°の壁。

## 手触りの層

| 層 | 中身 |
| --- | --- |
| カメラ | ボブ、着地ディップ、ヴォルト/クライム前傾8°、ウォールランで壁と反対へ10°ロール、スライドで目線-0.9 m・後傾5°、速度FOV |
| 体 | 腕振り、手を着く（ヴォルト/クライム/ぶら下がり）、ウォールランで壁側の手を添える、脚（走り・スライド・ぶら下がり） |
| 衝撃 | トラウマ方式の揺れ（ハードランディング0.5 / 高所ローリング0.25 / 壁激突0.6） |
| 振動 | 毎歩・着地・ハードランディング・縁を掴む・ウォールラン中・スライド中（速度に比例） |

## 10回走る時に見ること

1. 4層を全部ONで3回。気持ちよくない瞬間をメモする（どの技の、どのタイミングか）
2. 調整パネル（F1 / R3）で層を1つずつOFFにして、何が効いていて何が酔いの原因かを切り分ける
3. 数値を変える。エディタから実行していればSaveで `resources/movement_default.tres` に直接書かれる

## 体のモデルの制約

- 元モデルは骨格なし。指は開いたまま、脚は膝・足首で3分割した剛体パーツ。胴体は無い
- 手はカメラに付いている（ビューモデル方式）
- 骨格入りのフルボディに差し替えても、`arms.gd` / `legs.gd` の姿勢計算はそのまま使える
